# 🏠 LuckRent — Home Rental Website
A modern and responsive **home rental website for Lucknow**, designed to make finding rental properties simple, fast, and convenient.

## 🌐 Project Overview

**LuckRent** is a frontend home rental website that allows users to explore rental properties, search by location and budget, view property details, learn about the platform, and contact the rental team.

The project features a clean and modern UI with responsive design, animations, property cards, search functionality, and a contact section.

* 🏠 Modern home rental landing page
* 🔎 Property search section

### 1. Clone the Repository

```bash

```

### 2. Open the Project Folder

```bash

```
